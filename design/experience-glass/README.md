# Experience UI Hybrid Glass

Experience UI's original visual system combines three design directions:

- **One UI 8.5-inspired usability:** large page titles, rounded controls, generous spacing, clear settings groups and polished motion.
- **Liquid Glass-inspired surfaces:** translucent layers, luminous edges, restrained blur and subtle reflections.
- **Huawei-inspired glass ribbons:** flowing curves, iridescent highlights and cool blue/cyan/silver/violet lighting.

This is an original design, not an implementation of Samsung One UI, Apple iOS, or Huawei EMUI/HarmonyOS. Do not copy proprietary source code, logos, app assets or firmware artwork.

## Implementation requirements

- Maintain legibility over every glass surface.
- Provide light and dark themes and respect system theme where supported.
- Prefer cheap translucent surfaces over mandatory real-time blur.
- Respect accessibility contrast, font scaling and reduced-motion settings.
- Keep touch targets large and layouts adaptive for phones/tablets.
- Preserve existing app behavior and package names.
- Treat app redesign and privileged Android System UI changes as separate tasks.
- The boot animation is generated by `bootanimation/generate_bootanimation.py`.
- The boot animation is 1080×1920 at 30 fps with an original luminous-ring and flowing-glass-ribbon motif. Validate on the intended ROM/device before release.
